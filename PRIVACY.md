# Data and privacy

Library metadata, queue, recent listens, preferences, recommendation signals and downloaded files are stored on your device. The app does not send a listening profile to a Devil Music server.

Searching and streaming contact YouTube/YouTube Music services through NewPipe; artwork is fetched from validated provider URLs. Lyrics retrieval contacts LRCLIB and supported lyric sources. Those providers receive the network request, including your IP address and requested metadata. Android's system file picker grants access to local audio or an explicitly chosen import/export file.

No login is required for the public catalog. Unavailable, protected or region-restricted material may not play. Offline downloads are user initiated. Short next-track preloading is optional and uses network data.

Library transfer is explicit file export/import, not continuous cloud sync. Review files before sharing; collection metadata and preferences can reveal your music taste. Android backup is disabled for the preview. Removing the app also removes its private data.

Update checks contact the public GitHub Releases API once a day while the app is open, or when you choose Check for updates. GitHub receives a normal network request (including IP address); no library, listening history, device identifier or account token is sent. A small release-list cache and the last-check time are stored locally. APK downloads open in your browser and installation requires Android confirmation.
